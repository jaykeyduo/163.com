# 163.com · 出口危险品管理工具

## 当前主工具（V5）

用 Edge / Chrome 直接打开：

`dg-export-tool-v5.html`

- 工具版本：`5.0.0`
- 本地缓存键：`mkq-dg-export-v5`（与 V4/`mkq-dg-export-v1` **不共用**；打开 V5 不会自动带入旧缓存）

功能模块：

1. **包装性能单** — PDF/粘贴导入、清单编辑、多条件筛选、CSV/JSON 导出  
2. **危包证** — PDF/粘贴导入与清单  
3. **运单 DO** — Delivery Header + Product/Batch Item 行项目读取、筛选、导出  
4. **数据结合** — 框架占位  

样例 DO：`samples/do/83231976.pdf`、`samples/do/83255460.pdf`

### V5 相对 V4

- 正式升版：文件名 `dg-export-tool-v5.html`，页头标明 V5  
- 缓存键升级为 `mkq-dg-export-v5`  
- 含运单 DO 读取、纸箱标记修复、性能单多条件筛选
