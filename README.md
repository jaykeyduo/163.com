# 163.com · 出口危险品管理工具

## 当前主工具（继续修改）

用 Edge / Chrome 直接打开：

`dg-export-tool-v4.html`

功能模块：

1. **包装性能单** — PDF/粘贴导入、清单编辑、多条件筛选、CSV/JSON 导出  
2. **危包证** — PDF/粘贴导入与清单  
3. **运单 DO** — 框架占位  
4. **数据结合** — 框架占位  

### v4 近期修复

- 纸箱「包装容器标记及批号」漏读：支持 `4G/Yxx/S/yy` 与带尾部下划线 / 空格的 `CN/…PI`  
- 包装性能单多条件筛选（AND）：包装使用人 / 本单有效期截止 / 运输方式 / 包装容器标记及批号
