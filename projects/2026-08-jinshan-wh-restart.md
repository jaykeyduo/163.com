# 金山工厂物流重启 — 人力与资源评估

## 一句话目标

为金山工厂重启 **含硅 + 含铬** 生产，给出物流/仓库侧最低可行配置，并明确与独山主仓的边界，避免用独山加班硬撑。

## 背景（邮件 2026-08-07 ~ 08-11）

| 来源 | 要点 |
|---|---|
| Alex（生产） | 含硅 72 T/年；含铬 400 T/年；需物流仓配料/入库/叉车；另需出单打签、废弃物、保洁、管理人员等支持 |
| Liufei（仓） | 仓侧初案：**2人 + Backup 1人/独山**；前移式 1.4T ×1；平衡重 ×1；10号一楼物流办公（打印+电脑） |
| 现状叉车 | 2012 平衡重+前移（约14年，极差已停用）；2015 前移 **现役** |
| Roy | 投资表须加上 **平衡重叉车** 费用；请仓/公用工程跟进评估 |

## 货量粗算（物流负荷感）

| 品类 | 年产量 | 约月均 |
|---|---:|---:|
| 含硅 | 72 T | ~6 T |
| 含铬 | 400 T | ~33 T |
| **合计** | **472 T** | **~39 T** |

相对独山主仓库存 1500–2000 T、周作业约 46 万 KG，金山是 **小体量专用产线仓**；但含铬/含硅带来 **分区、合规、专岗技能**，不能按「吨数÷独山效率」直接缩人到 0。

## 结论（给厂长）

物流重启建议按 **「最小常驻编制 + 明确定义的独山备份 + 必投叉车/办公」** 推进：  
**常驻仓员 2 人**；独山 **约定 Backup（建议按班次/周次锁定，不是随叫随到）**；设备 **新购前移式 1 台 + 平衡重 1 台**（2012 年旧车不计入可用能力）；办公落在 **10 号一楼**。  
同时必须在投资清单外写清：**维修保养、现场管理覆盖、保洁、危化分区/合规** 的归属，避免再次变成「仓配兜底」。

## 选项

| 选项 | 人力 | 设备 | 对服务 | 对成本 | 对风险/合规 | 对独山工时 |
|---|---|---|---|---|---|---|
| **A. 邮件初案（推荐微调）** | 常驻 **2** + 独山 Backup **1**（制度化） | 新前移 1 + 新平衡重 1；留用 2015 前移作备用/过渡 | 可覆盖 472 T/年日常供产退仓 | CapEx 中等 | 需明确含铬分区与持证 | 有冲击，可控若 Backup 排班化 |
| **B. 金山自给** | 常驻 **3**，不依赖独山日常 Backup | 同上 | 韧性最好 | 人力成本更高 | 合规专岗更容易固定 | **保护独山** |
| **C. 超瘦身** | 常驻 **1** + 大量独山支援 | 尽量修旧利废 | 峰值易断 | 账面人少 | 旧车/单点人风险高；含铬不宜 | **显著恶化独山加班** — 不推荐 |

### 推荐

**推荐 A（对厂长汇报口径）**，附加四条硬条件：

1. **Backup 不是口头**：写清每周支援小时上限、触发条件（请假/峰值/开班）、费用归属（金山项目 vs 独山成本中心）。  
2. **2012 年两台停用车不计入产能**；投资表按 Roy 要求纳入 **新平衡重**；吨位由「单批投料 + 搅拌釜总重」定稿后再招标。  
3. **2015 前移**仅作过渡/备用，不替代「新前移 1.4T」配置（车龄与双产线并行风险）。  
4. **职责边界**：仓负责原料供产、成品/半成品入出、叉车作业、库存账实；**生产单/灌装单出单与标签打印**归系统责任部门（Shipping/计划/生产，待定一人牵头），不默认塞给仓员「顺便做」。

若厂长更担心独山加班红线被撕破 → 选 **B（3 常驻）**。

## 建议配置清单（物流视角）

### 人力

| 角色 | 人数 | 说明 |
|---|---:|---|
| 金山仓操作（常驻） | **2** | 覆盖叫料供产、退仓入库、叉车、基础盘点；双岗避免单点 |
| 独山 Backup | **1 人额度** | 建议：每月约定 X 人天，或指定 AB 角；非 7×12 随叫随到 |
| 现场管理 | **兼岗** | 独山仓主管/班长按节奏巡检（邮件「现场管理人员」）；不另设金山仓经理亦可，但要有周检清单 |
| 保洁 | **外包或工厂公共** | 仓+办公区域；不计入仓操作编制 |
| 维修保养 | **设备/工程** | 叉车维保合同；不由仓员兼主责 |

**粗负荷感（供解释用，非精密工时模型）：**  
~39 T/月产量对应的供产+退仓+搬运，在专线小仓用 2 人可行；含铬专项操作、单据、异常会吃掉余量 → 故保留 Backup，而不是砍到 1 人。

### 设备 / 设施（CapEx / 必配）

| 项 | 数量 | 状态建议 |
|---|---:|---|
| 前移式叉车 1.4T | 1 新 | 投资必列 |
| 平衡重叉车 | 1 新 | **Roy 已要求加入投资表**；吨位待工艺确认 |
| 2015 前移 | 1 现役 | 过渡/备用；评估剩余寿命与维保成本 |
| 2012 平衡重+前移 | 2 停用 | 报废/处置流程；勿计入可用 |
| 10号一楼物流办公 | 打印机+电脑 | 最小办公闭环 |
| 危化/含铬相关存储与标识 | 待 EHS | **合规门禁**，费用可能在工程/EHS 而非纯物流 |

### 持续 OpEx / 支持项（邮件已列，须写入厂长清单）

1. 设备维修保养（叉车）  
2. 现场管理人员覆盖  
3. 仓库及办公区域保洁  
4.（生产侧提出但属跨部门）出单打签、废弃物处置 — **指定主责部门**

## 与独山的接口（避免两套混乱）

| 主题 | 建议 |
|---|---|
| 库存与系统 | 金山仓独立库位/库存地；SAP 流程与独山叫料-退仓对齐，但账号与责任清晰 |
| 物料调拨 | 独山↔金山调拨规则、承运、危化资质事先定 |
| 人力 Backup | 排班进独山劳动力计划，避免周六加班无计划占用 |
| 考核 | 金山仓 KPI 独立（服务产线 OTIF、盘点差异、安全）；不简单摊进独山仓 KPI |

## 风险

| 风险 | 缓解 |
|---|---|
| 含铬合规/分区不足 | EHS 并联；无路径则推迟投产 |
| 独山 Backup 吞噬主仓工时 | 人天上限 + 提前一周申请 |
| 平衡重吨位不定导致错买 | 等工艺给出单批+釜重再下单 |
| 职责不清（打签/废弃物甩仓） | 厂长会上点名主责 |
| 旧叉车「凑合用」 | 投资表明确新购；旧车仅备用或报废 |

## Go / No-Go

| 判断 | 条件 |
|---|---|
| **物流侧有条件 Go** | 同意 2 常驻 + 制度化 Backup；新前移+新平衡重进投资表；EHS 含铬路径并行 |
| **建议升 B（3 人）** | 若独山 Backup 无法保证，或双班/含铬专岗要求更高 |
| **No-Go / 暂缓** | 无合格叉车方案，或危化存储合规未过 |
