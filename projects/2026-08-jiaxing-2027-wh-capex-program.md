## 1. 一句话结论

以 **一体 Program** 推进嘉兴厂内仓储能力升级：**8 号仓高密度货架 + VNA** 解决存储密度与存取效率；**5 号甲类仓温控试点** 解决温度敏感危化品在库风险。两项统一由联合小组管理、统一对管理层汇报，避免货架/叉车能力与温控合规脱节。

---

## 2. 为什么现在投（业务逻辑）

| 事实 | 含义 |
|---|---|
| 独山内仓约 80% 货量、全 BU、库存约 1500–2000 吨 | 主枢纽能力必须厂内解决 |
| 货以危化品为主（3/6/8/9）；5 号为 **甲类** | 温控必须按甲类危化要求设计，EHS 门禁 |
| UV/水性约 5–35°C；运输已有温控零担 | 仓储温控仍是断点 → 先试点甲类再扩展 |
| 仓库已有周六加班 | 用货位密度 + VNA 效率换工时，而非加人 |
| 货架设计已完成且仓库已确认 | WP-A 执行风险低于「从零规划」 |

### 本计划边界（不膨胀）

- 不含：出口欧洲/东南亚、储罐卸货治理、外仓 3PL 策略  
- 乙类仓温控：**明确二期观察项**，不纳入本期必投范围

## 3. 投资组合（已定范围）

| WP | 范围（已定） | 状态 |
|---|---|---|
| **WP-A** | **8 号仓库**：新设货架（供应商已出设计，仓库已确认）；采购 **2 台 VNA** 专配 8 号仓 | 范围冻结；预算区间已知 |
| **WP-B** | **5 号甲类仓间**温控设计与实施（目标约 5–35°C）；**乙类仓暂不铺开**，试点评估后再议 | 范围冻结为试点；**设备概算待补** |

**一体推进含义（在已定形态下）：**

- 同一联合小组、同一汇报节奏、同一投用窗口（2027 年中）  
- WP-A 与 WP-B 场地不同（8 号 vs 5 号），但合规审查、验收标准、工时/质量 KPI 统一管理  
- 乙类铺开的 Go/No-Go 绑定 WP-B 试点复盘，不另起无数据叙事

## 8. 风险与合规

| 风险 | 缓解 |
|---|---|
| 甲类仓温控的防爆/消防要求严于普通仓 | EHS 从方案阶段进联合小组；合规为门禁 |
| VNA 通道、地面平整度、货架公差不匹配 | 货架公司设计已确认；安装前做联调检查清单（工程+仓） |
| 只上设备不改 SOP | 投用门槛含 VNA 操作/温控巡检 SOP 与培训记录 |
| 乙类被默认为「已批准铺开」 | 材料与会议纪要写明：**乙类 = 试点后决策** |
| WP-B 概算空白导致总盘不准 | P1 完成前不宣称 Program 总投资终值 |
