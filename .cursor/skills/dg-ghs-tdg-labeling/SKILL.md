# 危货物流：GHS vs TDG 贴标 Skill

## 何时使用

用户问到下列任一主题时，**先读再答**：

- `knowledge/07-compliance/ghs-tdg-mapping.md`（对照总表 + 仓配规则）
- 相关产品：`knowledge/02-products/*`（若涉及具体料号/出口包装）

## 核心原则（不可违背）

1. **运输标签 = TDG**（分类鉴定报告 + SDS **第 14 章**），不是 GHS。  
2. **GHS（SDS 第 2 章）象形图 ≠ 运输标**。  
3. GHS「腐蚀」图可能来自皮肤腐蚀 / **严重眼损伤** / 金属腐蚀；**严重眼损伤 alone → 非 TDG 第 8 类**。  
4. **副标**仅当运输信息写明副危（如 6.1、8）时加贴。  
5. 鉴定与 SDS14 冲突 → 停贴并升级 EHS/进出口，不自行选择。  
6. Agent **不签发**正式危货分类或法律意见。

## 答题步骤

1. 确认用户依据的是：鉴定报告 / SDS14 / SDS2 GHS / 口头传闻。  
2. 用对照表说明该 GHS 条目是否映射到 TDG 类。  
3. 给出仓配动作：贴哪些运输标 / 不贴什么 / 需要哪份受控文件。  
4. 公路 vs 海运（鱼树/海洋污染物）若相关，分开说。  
5. 若为企业长期口径，提醒更新 `ghs-tdg-mapping.md` 第 6 节料号实例表。

## 输出偏好

- 中文、短句；先给「是否该贴」结论。  
- 用小表对比：GHS 所见 | TDG 应贴 | 依据文件。  
- 需要培训时：指向对照表「仓配最易错点」。
