# 危货物流：GHS 象形图 + GHS vs TDG 贴标 Skill

## 何时使用

用户问到下列任一主题时，**按序阅读**：

1. `knowledge/07-compliance/ghs-pictograms.md` — GHS01–09 象形图代表哪些危害  
2. `knowledge/07-compliance/ghs-tdg-mapping.md` — 该危害是否对应 TDG 运输类 / 如何贴运输标  
3. 具体料号时：`knowledge/02-products/*`

## 核心原则（不可违背）

1. **GHS 象形图**（SDS 第 2 章 / 货架标签）≠ **TDG 运输菱形标**。  
2. **运输标签**只认分类鉴定报告 + SDS **第 14 章**。  
3. **GHS05 腐蚀** 可因皮肤腐蚀、金属腐蚀或 **严重眼损伤 Cat.1** 出现；仅眼损伤 → **不贴** TDG 第 8 类。  
4. **副标**仅当运输信息写明副危（如 6.1、8）时加贴。  
5. 鉴定与 SDS14 冲突 → 停贴并升级 EHS/进出口。  
6. Agent **不签发**正式危货分类或法律意见。  
7. GHS03 识读时记得含 **氧化性固体**（部分公开表漏列）。

## 答题步骤

1. 分清用户拿的是：GHS 图 / 鉴定 / SDS14 / 口头。  
2. 若问「图是什么意思」→ 查 `ghs-pictograms.md`。  
3. 若问「要不要贴运输标」→ 再查 `ghs-tdg-mapping.md`。  
4. 输出小表：GHS 所见 | 含义 | TDG 应贴否 | 依据文件。  
5. 公路 / 海运（鱼树）分开说明。

## 输出偏好

- 中文、短句；先给结论。  
- 培训场景强调：GHS05 与第 8 类运输标的区别。
