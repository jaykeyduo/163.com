# 物流单证周数据库（带 UI）

在公司现有环境内运行的数据录入工具：**PowerShell 5.1 + WinForms + Excel**，无需管理员权限、无需安装额外软件。

## 功能

- 手工录入（各字段可 `Ctrl+V`）
- 从 Excel 复制整行/多行后粘贴提交（Tab 分隔，可含表头）
- 上传 Excel/CSV（按模板列）提交
- 数据写入后台 Excel：`WeeklyDatabase.xlsx`
- 上限约 **1000 条**，保留约 **7 天**（按「录入时间」清理）

## 部署（推荐）

云端 Agent **无法直接写入**你本机的 `Y:` 盘。请在公司电脑上任选一种方式：

### 方式 A：一键部署脚本
1. 从仓库下载/拉取 `客服单证周数据库` 文件夹到本机任意位置
2. 确认已映射 `Y:` 盘
3. 双击 `Deploy-To-Y.bat`
4. 脚本会复制到：

   `Y:\03_Exchange\03_Among Supply Chain\05_物流单证\Tool\周数据库\`

5. 再双击该目录下的 `Start.bat`

### 方式 B：手动复制
把整个文件夹复制到：

`Y:\03_Exchange\03_Among Supply Chain\05_物流单证\Tool\`

确认本机已安装 **Microsoft Excel**。如需改字段：编辑 `config.json` 中的 `columns`，保存后重新打开程序。

## 默认字段（可改）

| 字段 | 必填 |
|------|------|
| 日期 | 是 |
| 单号 | 是 |
| 客户 | 否 |
| 业务类型 | 否 |
| 内容摘要 | 否 |
| 状态 | 否 |
| 备注 | 否 |

系统自动追加：`录入时间`、`录入人`。

## 使用简述

1. **手工录入**：填表 →「提交到数据库」
2. **粘贴**：在 Excel 选中含表头或不含表头的行 → 复制 → 到「粘贴整条/多条」粘贴 → 预览 → 提交
3. **上传**：「导出上传模板」→ 填写 →「上传 Excel」浏览并预览 → 提交

## 验证清单（公司电脑）

1. 双击 `Start.bat`，窗口正常打开
2. 手工提交 1 条，在网格中可见
3. 打开 `Tool\WeeklyDatabase.xlsx`（或程序旁 `data\` 兜底目录），确认有新行
4. 从 Excel 复制 2 行粘贴提交成功
5. 用模板 CSV/XLSX 上传提交成功
6. 记录数接近 1000 时拒绝超额提交
7. 「清理过期」可去掉超出保留期的行

## 说明

- 若启动时找不到 `Y:\...`，会提示并写入程序目录下 `data\`（便于离线试跑）；公司电脑有 Y: 盘时写回配置路径。
- 共享盘上 Excel 若被他人打开锁定，程序会自动短重试；仍失败时关闭占用后重试。
- PAD unattended 不使用；本工具为本地 attended 桌面程序。
