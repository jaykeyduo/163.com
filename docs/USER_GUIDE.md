# 危险品出口包装与运输标签审核工具 · 用户操作说明

## 启动

1. 使用 Microsoft Edge 或 Google Chrome 打开 `dg-export-audit-tool.html`（可双击，无需服务器）。
2. 工具为**完全离线**单文件：不登录、不写 Cookie、不使用浏览器本地存储、不访问外网。
3. 关闭浏览器后内存会话丢失；请及时使用「导出审核JSON」保存。

## 典型流程

1. 首页点击「新建审核任务」，系统自动生成审核编号并锁定演示规则版本。
2. **步骤1** 填写产品、物料号、目的港、出运日期等必填项。
3. **步骤2** 勾选已备资料，录入 SDS / 鉴定书 UN 号与有效期；注意 DOC-001～005 一致性规则。
   - DOC-003 允许「油漆/涂料」等类别前缀、空格和连字符差异。页面会显示步骤1产品名称。
   - 若名称确实不是同一产品，使用「用步骤1名称填入 SDS/鉴定书」或「以 SDS 名称为准写回步骤1」后再点下一步。
4. **步骤3** 输入 UN 号（演示：1263 / 3066 / 3469 / 3470），点击「载入 DGL 与全部 SP」。
5. **步骤4** 对每条命中的特殊规定分别确认。
6. **步骤5** 填写 LQ/EQ 参数并选择实际运输路径，写明未选其他路径的原因。
7. **步骤6** 从包装主数据选择包装，填写装量、毛重、密度，确认证书覆盖。
8. **步骤7** 按清单勾选标记标签项，并人工确认样稿。
9. **步骤8** 填写审核人/批准人，查看汇总报告，使用浏览器打印或另存 PDF。

## 闸门状态

| 状态 | 含义 | 是否可继续 |
|------|------|------------|
| 通过 | 强制条件满足 | 是 |
| 有条件通过 | 有待办，报告保持黄色 | 可继续评估，最终不得无条件放行 |
| 资料不足 | 关键输入缺失 | 否 |
| 不通过 | 明确不符合 | 否 |
| 专家复核 | 超出自动范围或冲突 | 需专家覆盖批准后继续 |

## JSON 导入导出

- **导出审核JSON**：保存当前任务全部字段与判定快照。
- **导入审核JSON**：从文件恢复任务（可用 `docs/sample-audit.json` 试用）。
- **导出规则JSON**：导出内嵌演示规则库，供比对或线下维护。
- **清空当前任务**：会先提示导出，确认后清空内存中的当前表单。

## 重要声明

本工具仅用于企业内部预审，**不替代**危险特性分类鉴定、法定检验、海事申报、主管机关或承运人最终审核。演示规则字段均标记为 DEMO。
