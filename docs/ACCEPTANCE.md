| AC-02 | 源码不含外部 URL、登录 SDK、Cookie 或浏览器存储依赖 | 脚本扫描 `http(s)://`、`localStorage`、`sessionStorage`、`cookie`、`indexedDB` | PASS |

## 自动化静态检查

见仓库脚本 `scripts/ac-check.mjs`（或内嵌 shell 扫描）。关键负面用例：

1. DOC-001：SDS UN=1263，鉴定 UN=3066 → 专家复核，不可进入后续自动放行。
2. DOC-002：报告到期日早于今天 → 不通过。
3. DOC-005：勾选“仅客户标签” → 禁止自动判定。
4. 包装 PG II + 性能等级 Z → 不通过。
5. 规则库无 UN9999 → 专家复核，不自动生成分类。

## 已知限制与人工复核清单

- 演示 DGL / SP / LQ / EQ / P001 数值均为 DEMO，须授权人员复核后才能作为正式依据。
- 离线版以勾选代替真实附件上传与 OCR；不解析 SDS PDF。
- 无账号权限、无服务端审计、无不可篡改历史库（V1 用 JSON 文件自行留存）。
- 空运/公路/铁路、罐柜/IBC/散装、温控、有机过氧化物默认转人工。
- 标签图形仅为示意，颜色、尺寸、位置、耐久性必须人工确认。
- 承运人、目的港、中国危包证属地附加规则仅通过 SP944 占位提示。
- 会话仅存内存；未导出即关闭页面会导致数据丢失。
