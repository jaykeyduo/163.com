# 嘉兴仓储投资 Program 方向决策

- 日期：2026-08-04
- 决策结果：**Approved（方向）** / 金额终裁 Pending（待温控概算）
- 相关项目：`projects/2026-08-jiaxing-2027-wh-capex-program.md`

## 背景

需向厂长/总经理提交 2027 视距仓储投资：将已在推进的仓能力投资与温控采购做成系统计划。

## 选项

- A 一体推进 / B 先仓后温控 / C 先温控后仓 / D 两份独立申请

## 建议（及依据文件）

采纳 **A**。依据：`knowledge/05-strategy`、`03-network`、`02-products`；详见 Program 文件。

## 已批准范围

- WP-A：8 号仓货架（设计已确认）+ VNA ×2；预算约 210–230 万 RMB  
- WP-B：5 号甲类仓温控试点；乙类暂缓  
- 投用：2027 年中  
- 治理：物流+工程+EHS+生产+财务联合小组  

## 风险

- 甲类温控合规；VNA 与货架匹配；WP-B 概算未齐

## 待确认

- 温控设备概算与 EHS 路径；合同价锁定

## 最终决定与负责人

- 方向：物流经理确认的五件事已写入 Program §9  
- 金额终裁：待联合小组提交完整概算后请总经理批准  

## 后续动作

- 组建联合小组；并行推进 WP-A 采购与 WP-B 方案报价
