# 首出口：1st time export test = Lead-time（同一动作）

- 日期：2026-08-12
- 决策结果：Approved（Jason 口头确认，写入知识库）
- 相关：`knowledge/02-products/export-packaging-un.md`、`export-process-revised.*`

## 背景

对照 ByRoy `Export Process Procedure` 与 Phase I/II 纪要时，曾把图中「1st time export test」与纪要「首出口 Lead-time」当作可能不同的两段。

## 最终决定

二者为 **同一动作**（该国首次出口触发的海关检测/测试及其交期占用）。

- 申请/排产：只做「是否首出口」**判定**，并把 Lead-time 写入计划 Milestone  
- 出运 Phase IV：**执行**该测试（ByRoy 节点），不另画第二套流程  
- 待补：该动作占用的 **天数** 及影响哪些 Milestone（仍由 Jason 回填）
