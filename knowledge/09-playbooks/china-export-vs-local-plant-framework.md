# 决策框架：中国现有工厂出口 vs 墨西哥/泰国建厂

## 1. 用途与边界

用于回答：**用嘉兴/独山（及金山）现有产能供应墨西哥或泰国客户，还是在当地建涂料厂。**  
本文件是**分析框架**，不是 Go/No-Go。产量、运费、关税、CapEx 未写入本库前，**禁止填假精确 ROI**。

**已知事实（本库）：**

- 中国销售约 **99% 内销**；出口在拓展；欧洲尚无稳定线路  
- 出口卡点是 **危货出口能力 + UN 包装/性能单/危包证闭环**，不是「没有船」  
- 泰国：已有样品/订单级出口尝试（Nage 等），包装抬头与性能单已暴露能力缺口  
- 墨西哥：本库**无**美凯威奇当地工厂/仓节点；竞品 PETER/LACKE 在克雷塔罗有生产+仓  
- 集团在多国有厂（汉堡 HQ），中国物流 Agent **不能默认**墨西哥/泰国已有集团工厂——须先向集团确认  

**默认优先级（`AGENT.md`）：** 合规 > 人力边界 > OTIF > 韧性 > 总成本 > 碳。

---

## 2. 先拆两国、再拆选项（禁止捆成一个答案）

墨西哥与泰国在关税同盟、危货规则、客户集中度、与中国的海运半径上不同，**必须分国评分**，再看是否共用「出口能力平台」。

| 比较轴 | 墨西哥 | 泰国 |
|---|---|---|
| 与中国工厂关系 | 远洋；常经美墨供应链/USMCA 客户 | 近距东南亚；已有出口试点 |
| 客户结构（待填） | OEM / Tier / 再出口美国？ | 本地 OEM / 工业 / 样品转量产？ |
| 贸易安排（待核） | USMCA、对华关税 | 中国—东盟等 |
| 公开对标 | 竞品已在 MX 建厂 | 可用中国出口先验证需求 |
| 本库项目锚点 | 无 | `projects/2026-08-export-dg-sea.md` |

## 3. 标准选项集（每国从中选，可组合）

| 代号 | 选项 | 含义 |
|---|---|---|
| **A 出口型** | 中国工厂灌装出口 | 独山（默认抬头）成品/样品 → 海/空 → 客户或当地 3PL |
| **B 前置仓** | 中国产 + 当地保税/危货仓 | 不建厂；建库存与本地配送 |
| **C 轻本地** | 当地调漆/分装/稀释 | 基料中国出口，当地完成客户化（须单独合规评估） |
| **D 建厂** | 当地完整涂料工厂 | 生产+仓+危化许可+本地供应链 |
| **E 集团协同** | 由已有第三国工厂供应该国 | 仅当集团确有 MX/TH/邻近工厂时启用 |

推荐讨论顺序：**先 A 把出口能力做实 → 需求稳定后评 B/C → 门槛满足再评 D**。  
建厂是资本与组织决策，标为「待集团/战略确认」。

---

## 4. 五道门槛（任一道不过，不得推荐 D 建厂）

1. **需求门槛：** 可持续订单（不是一次性样品）；SKU、年吨、OTIF/交期承诺书面化  
2. **合规门槛：** 该国危化生产+仓储许可路径清晰；出口国危包证/鉴定可闭环 *或* 当地可替代  
3. **供应门槛：** 关键树脂/颜料/溶剂当地可购或可进口；人员与配方转移可行  
4. **服务门槛：** 客户是否要求本地实验室/颜色/48–72h 响应（仅出口无法满足则倾向 C/D）  
5. **资本门槛：** 当地建厂 vs 把同等资本投在**中国出口能力**（UN 包装、S2/S3、空运证、人力）的机会成本

门槛 1–2 未过：默认停在 **A**，并行补出口包装治理。

## 5. 评分维度（每国一张表）

对每个选项打 1–5（5=优）。权重建议（可改，须书面）：合规 25%、OTIF/交期 20%、韧性 15%、全成本 15%、能力占用/组织 15%、碳 10%。

| 维度 | A 中国出口 | B 前置仓 | C 轻本地 | D 建厂 | 数据从哪来 |
|---|---|---|---|---|---|
| 危货/海关/许可 | 中国出口证+目的国进口 | +当地仓许可 | +分装许可 | 完整生产许可 | EHS/进出口 |
| 交期 OTIF | 海运周级；空运贵 | 本地有库存则短 | 短 | 最短（达产后） | 销售承诺、船期 |
| MOQ / 样品灵活性 | 受出口批次与换桶约束 | 中 | 高 | 达产后高 | PC/销售 |
| 包装 UN/性能单 | **强依赖中国采购 S2/S3** | 同左+再包装风险 | 当地包材新证 | 当地包材体系 | 采购 RACI |
| 关税+运费+库存资金 | 运费高、在途库存 | 仓租+安全库存 | 中 | 运费低、CapEx 高 | 财务/物流 |
| 关税/原产地 | 中国原产 | 同左 | 可能仍中国原产 | 当地原产潜力 | 关务 |
| 需求不确定性 | 可撤退 | 仓合同有退出成本 | 中 | 沉没成本高 | 销售预测质量 |
| 组织/工时 | 占中国出口与仓人力 | +海外仓管理 | +海外运营 | 新法人与工厂 | 物流/HR |
| 对标竞品 | 慢于已建厂对手 | 中 | 中 | 对齐「当地服务」 | 公开情报 |

**硬否决：** 无法取得合法危货进出口或当地生产许可 → 该选项淘汰。

## 6. 成本应算「全供应链」，禁止只比运费

每国、每选项用同一口径（缺数则写「未知」）：

```text
全成本 ≈ 制造 + 出口包装/性能单/危包证摊销 + 国际运保 + 关税/VAT
        + 目的国清关/内陆 + 安全库存资金 + 质量/换货
        + 组织成本（中国出口团队 vs 当地工厂固定成本）
        + 碳（可选，优先级最低）
```

建厂另列：**土地/租赁、甲类仓、环评、许可、设备、配方转移、爬坡损耗、关厂期权**。  
中国出口另列：**把出口能力从「有限」补到稳定运行的一次性治理成本**（包装主数据、空运证、抬头一致、培训）。

## 7. 出口能力诊断（决定 A 能走多远）

在讨论建厂前，对中国出口能力打分（0–2 分/项）：

| 能力 | 0 | 1 | 2 |
|---|---|---|---|
| 工厂抬头与鉴定/危包证一致 | 经常错位 | 个案能对 | S3 受控默认独山 |
| 海运包装闭环 | 无稳定证 | 单国可走 | 多料号可重复 |
| 空运包装/性能单 | 未确认 | 供应商口头 | 书面分证在库 |
| 采购适用性声明 | 推给出口 | 部分 | 门禁强制 |
| 交期承诺 | 无法给客户日期 | 缓冲很大 | Milestone 含首出口 Lead-time |
| 目的国进口 DG | 未核 | 代理可做 | 自有清单 |

**总分偏低：** 优先投资 **A 的能力建设**，而不是用建厂逃避中国出口治理。  
**A 已稳定且需求越过门槛 1：** 再认真评 B/D。

## 8. 分阶段路径（推荐叙事）

```text
阶段 0  集团确认：MX/TH 是否已有工厂或指定第三国供货
阶段 1  需求画像：客户、吨、SKU、交期、是否再出口
阶段 2  用泰国（近、已有试点）把中国出口平台跑通
阶段 3  墨西哥：先算关税+交期；A 或 B；D 仅当客户绑定/USMCA 原产地有强制价值
阶段 4  复盘：出口占比、OTIF、包装异常、当地竞品动作 → 触发建厂门槛
```

泰国更适合做 **出口能力试验田**；墨西哥更可能因 **供应链近岸/原产地** 提前触发 D——须数据证明，不预设。
