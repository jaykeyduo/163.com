## 口径

- **净重**：可按行汇总  
- **运费**：同一 Delivery 多物料行重复带运费 → 分析运费时按 Delivery 取一次（MAX）再汇总  
- **温控要求**：`物料需要保温` 两类：`35℃以上/0℃以下`、`30℃以上/0℃以下`

### 客户视角结论

1. **温控运输服务高度集中**：少数大客户 + 内部移库吃掉大半货量/运费。  
2. **内部移库是运费第一大头**（上海→长春），与长春汽车外仓叙事一致；优化仓网/批量/频次可能比砍单票单价更有效。  
3. **频次型 vs 批量型**：慈溪福尔达 Delivery 最多但净重非第一；南通艾郎票少量大 → 不同服务模式。  
4. **SEW 多点**（天津/武汉/沈阳/西安等）适合谈：**温控线路打包/预约窗口/合并发运**。  
5. 与战略「客户需求多样化」：温控要求本身已分 30℃/35℃ 两档，客户侧还可再看是否叠加标签等（本表无标签字段）。

### 结构观察

| 类型 | 代表 | 特征 |
|---|---|---|
| **大单专用料** | `34020.7035.W.5W3` | 一客一料，占净重约 **12.6%** |
| **广谱配套料** | `60518...650`、`34577...002` | 客户数 47–48，Delivery 极多 → 几乎「温控标配」 |
| **30℃ 高频料** | `75724/75725`、`60518` | 跨多客户，适合标准温控产品组合 |
| **35℃ 主体** | 首字母 3 | 净重约 **84%** |

### 物料视角结论

1. **温控仓/车能力应按 35℃ 档为主需求设计**（货量主体）；30℃ 为第二档但频次不低（广谱料）。  
2. **库存温控（5 号甲类试点）优先清单**可先锁：Top 货量物料 + 广谱高频料（`60518`、`34577`、`75724`）。  
3. **运输温控**：广谱料高频 → 更适合固定温控线路/承运商产品，而非一单一议。  
4. 大单专用料（南通艾郎）适合 **专车/预约 + 质量协议**，与散客拼车逻辑不同。

## 对既有战略/投资的含义

- 支撑「成品+原料温控、非温控仓不够」：运输侧已有大量强制温控出货。  
- 支撑仓网：移库上海-长春运费与货量显著 → 外仓补货策略值得单独项目评估。  
- CapEx 温控试点验收指标可加：温控出货相关物料在库超温事件、对应客户 OTIF。
