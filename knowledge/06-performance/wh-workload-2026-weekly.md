# 嘉兴仓库周工作量（2026，按 KG）

## 字段说明

| 列 | 含义（业务理解） |
|---|---|
| ISO Week | ISO 周次 |
| Internal Transfer – Return (KG) | 内部转运：退回仓库（含生产退运等） |
| Internal Prod for Outbound (KG) | 内部生产相关出库 |
| External Prod for Inbound (KG) | 外部生产/到货入库 |
| Internal Transfer – Supply (KG) | 内部转运：供给（含供生产等） |
| Storage bin combination | 并入总量的库位合并类作业量（单位按表计入 KG 总量） |
| Total work 总量 (KG) | 当周作业总量 |
| Working hours 工时 (H) | 当周工时 |

> **数据可信度：** 总量与工时以用户表格为准。分项 KG 由截图转录，与总量存在少量尾差（通常几十 KG 级），分析时优先用 **总量 / 工时**。  
> 缺周：ISO **1、13、19**（表中未给出）。  
> **已确认：** 周 **7–8 = 春节**；**Working hours 含加班**。分析「常态」时剔除 W7–W8。

## 与已知战略/投资的关联（观察，非结论）

1. **退运/供给类内部转运约占四成** → 与「危化品法规 → 生产退运库存上升」「仓↔生产接口需优化」叙事一致，可作后续论证数据底。  
2. **多周工时 550–630H** → 支撑「已存在高工时/加班压力」；CapEx 验收可对照投用前后周工时与 KG/H。  
3. **W5 峰值近 68 万 KG** → 能力与甲类仓容讨论应看峰值而非仅均值。  
4. 本表是 **进出作业 KG + 工时**，不是即时库存利用率；**5 号甲类 80–85%** 仍以仓容专题数据为准，二者互补。
