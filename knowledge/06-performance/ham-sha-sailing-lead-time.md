# 汉堡→上海海运航行时间 — 内部 sailing lead-time 设置

## 1. 工厂口径（以此为准）

票数不加权：同一航次上柜量是运气，不代表航次快慢。

**计算步骤**

1. 以 **出发航次** 为统计单元（建议键：`ATD 日期` + `Route`；同船同开航日合并为一航次）。  
2. 航次航行日 = 该航次下各票 `(到港日 − ATD)` 的 **算术平均**（仅用于得到该航次一个数）。  
3. 只保留 **已到港** 航次（不用 ETA/Not Arrived）。  
4. 取这些航次中，开航日落在 **近 3 个完整月** 的集合，对 **航次航行日再做等权算术平均**（一航次一票权重）。  
5. 每月滚动重算，写入计划主数据 **sailing LT**。

```text
sailing_LT = mean( voyage_avg_days )  
             where voyage arrived = Yes  
             and ATD in last 3 complete months
```

**禁止：** 按 40'/票数加权；把未到港 ETA 纳入；用 MIN/全样本 AVG/单票 MAX 当主参数。

---

## 1b. 覆盖率（工厂指定算法）

**记录 = 透视表已到港的每一行（每个 ATD 的 AVG 航行日），一行一条、等权。**

升序排列后：

```text
k = CEILING(n × 覆盖率)     // 覆盖率用 0.80 / 0.85 / 0.90 / 0.95
L = 正序第 k 条的航行天数
```

与案例一致：n=6、80% → k=CEILING(4.8)=5；90% → k=CEILING(5.4)=6。  
不用 PERCENTILE 插值，不用票数加权。

近 3 个月 / 近 6 个月：把窗口内**所有已到港行的 AVG 放进同一个列表**再算 k，不要每月先算再平均。

### 案例：2026-03（用户提供 6 条）

AVG：46, 50, 51, 49, 49, 55  
正序：46, 49, 49, 50, **51**, **55**

| 覆盖记录条数 | k = CEILING(6×r) | sailing LT（天） |
|---|---|---|
| 80% | 5 | **51** |
| 85% | 6 | **55** |
| 90% | 6 | **55** |
| 95% | 6 | **55** |

### 近 3 个月 / 近 6 个月（待明细行）

窗口：3 个月 = 2026-03～05；6 个月 = 2025-12～2026-05（已到港行）。  
除 3 月这 6 条外，其余各月每一行 AVG 尚未提供，**不能拼出 n、也不能出 L**。

| 覆盖率 | 近 3 个月 L | 近 6 个月 L |
|---|---|---|
| 80% | 待 3–5 月全部已到港行 AVG | 待 12–5 月全部已到港行 AVG |
| 85% | 同上 | 同上 |
| 90% | 同上 | 同上 |
| 95% | 同上 | 同上 |

Excel：`=INDEX(SORT(AVG列), ROUNDUP(COUNTA(AVG列)*0.8, 0))`（85/90/95 改乘数）。

## 2. 当前可算的近似值（缺航次清单时）

今日（2026-08-19）：6–8 月多为未到港 → **近 3 个已到港完整月 = 2026-03、04、05**。

表中月 AVG 仍是票数加权，**不是**航次等权。在尚无航次表时，仅作 **等权月均近似**（每月一个数、等权）：

| 月 | 表内 AVG（票加权，仅近似） |
|---|---|
| 2026-03 | 49 |
| 2026-04 | 52 |
| 2026-05 | 55 |
| **等权三月均** | **52** |

→ 在取得按 ATD 航次重算前，内部 sailing LT **暂用 52 个日历日**。  
有航次表后，用第 1 节公式替换 52，不以票数重算。

## 3. 计划落地

| 参数 | 规则 |
|---|---|
| SAP/计划 sailing LT | = 上式滚动结果（现近似 **52**） |
| 更新频率 | 每月初，用已到港近 3 完整月航次等权平均 |
| 中转 | 若主参数只服务默认 HAM-SHA：计算时剔除 SIN/BRV/GBLON 等航次；中转票单独跟踪，不拉高直航 LT |
| 全链进口 | 独山可用日 = sailing LT + 清关 + 洋山→独山 + 仓过账（后三段另测） |

不再使用此前按票加权得到的 55/58 作为官方口径。
