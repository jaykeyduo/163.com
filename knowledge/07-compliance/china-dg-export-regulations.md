# 中国出口危险货物 — 物流部法规地图

> **用途：** 嘉兴出口危货时，物流/进出口用来判断「这一段归哪部法规、缺哪张单、该找谁」。  
> **不是正式法律意见。** 分类、许可、输入国符合性以 EHS / 法务 / 属地海关当面口径为准。法规会修订，作业前核官方最新文本。  
> **涂料语境：** 国内成品以第 3 类为主，固化剂多为第 8 类，亦见 6.1 / 9 类；出口欧洲尚无稳定线路，本文件先把**中国出境段**闸门写清。

---

## 1. 物流先分清的三套身份

同一桶漆可能同时是、也可能只是其中一种。报关、订舱、贴标用错身份，是最常见的卡单原因。

| 身份 | 判定依据 | 物流后果 |
|---|---|---|
| **危险化学品** | 《危险化学品目录》（现行公开版为 **2015 版**，含第 **2828** 项：含易燃溶剂的合成树脂、油漆、辅助材料、涂料等制品，闭杯闪点 ≤60℃） | 海关按 **129 号公告**做进出口检验；目录内产品**即使未列入法检目录**也要报检 |
| **危险货物（运输）** | UN TDG / IMDG / IATA / JT/T 617；企业内部以 **分类鉴定报告 + SDS 第 14 章** 为准 | 必须用 UN 包装、运输菱形标、危包使用鉴定（豁免除外）；海运还要海事申报与装箱证明 |
| **普通化工品** | 未入目录、运输上也不构成危险货物 | 不走危货包装/海事危货通道；仍可能有普通商检或许可证 |

**GHS ≠ TDG：** SDS 第 2 章象形图不能单独决定运输类别或是否出口法检。对照见 `ghs-tdg-mapping.md`。

**涂料特别点：** 闭杯闪点 ≤60℃ 的溶剂型涂料/稀释剂，实务上常同时落在目录 **2828** 与运输 **UN 1263 / 第 3 类**。水性漆可能非危——以鉴定和 SDS14 为准，不得口头当普货订舱。

## 2. 出境主链：每一段看什么

```text
分类鉴定 + SDS/标签
        → UN 包装（性能单）+ 灌装/装箱
        → 危包使用鉴定（使用鉴定结果单）
        → 产地海关危化品检验（符合性声明等）→ 电子底账
        → 公路危货运输至港区/机场
        → 订舱 / 海事货报+船报 / 港口作业
        → 集装箱现场监装 + 装箱证明书（海运）
        → 报关放行 → 装船/装机
```

| 环节 | 物流要卡住的法规点 | 常见交付物 |
|---|---|---|
| 产品能不能按危货出 | 目录 + 分类鉴定 + SDS14 | 鉴定报告、SDS（含外文及中文译件） |
| 桶/箱能不能装 | 《商检法》第 17 条；SN/T 0370 | 性能检验结果单；实物 UN 标记与证一致 |
| 这一票灌装是否合格 | 同条：使用鉴定；129 号公告第七条 | 《出境危险货物运输包装使用鉴定结果单》 |
| 海关放不放行 | 条例第 6 条（三）+ 129 号公告 | 符合性声明、产地检验电子底账、标签/SDS 样本 |
| 路上怎么运 | 道路危货规定；JT/T 617；管理办法 | 危货承运资质、托运清单、包装无破损渗漏 |
| 港区/船上 | 海上交通安全法；船舶载运危货规定；GB 40163 | 适运申报、进出港申报、装箱证明书 |
| 空运 | 《民用航空危险品运输管理规定》+ IATA DGR / ICAO TI | DGD、托运人培训、空运适用包装 |

## 3. 分层法规索引（物流常用）

下表按**效力与使用场景**排列。作业引用时写「文件名 + 条款」，不要用俗称代替。

### 3.1 法律 / 行政法规（底线）

| 文件 | 物流为什么要知道 |
|---|---|
| 《危险化学品安全管理条例》（国务院令第 591 号，及后续修改） | 进出口危化品及其包装由海关检验；生产/储存/运输另有应急管理与交通职责 |
| 《进出口商品检验法》**第 17 条** | 包装厂必须做**性能鉴定**；出口危货生产企业必须做**使用鉴定**；未经鉴定合格的包装**不准出口** |
| 《进出口商品检验法实施条例》第 29、51 条 | 使用鉴定的实施条款；未鉴定或不合格包装可处罚（实施条例规定罚款幅度） |
| 《海关法》及报关相关规定 | 如实申报；监管证件与检验电子底账随报关 |
| 《海上交通安全法》第 64 条一带 | 船舶载运危险货物进出港口须经海事许可/报告 |
| 《港口法》及《港口危险货物安全管理规定》 | 港区仓储、装卸须具备危货作业资质（选港区仓/3PL 时查附证） |
| 《出口管制法》及两用物项目录 | 涂料成品多数不在此列，但溶剂/中间体可能撞上；物流不自行放行 |

### 3.2 海关（出口报检 / 危包证）

| 文件 | 要点 |
|---|---|
| **海关总署公告 2020 年第 129 号**（2021-01-10 起；替代原质检总局 2012 年第 30 号） | 对《危险化学品目录》列明的进出口危化品实施检验。出口报检材料见下节 |
| 《进出口危险品及其包装检验作业指导书》（海关内部作业） | 现场抽检/验证口径；企业见单证与海关通知 |
| 稽查函〔2024〕17 号「批次检验」试点 | **高级认证等试点企业**可将部分现场检验改为周期内单证验证；未纳入试点仍按批检验。嘉兴是否试点：**待补** |
| SN/T 0370.1/.2/.3-**2021**《出口危险货物包装检验规程》 | 性能检验、使用鉴定的技术程序与证书有效期算法 |

**129 号公告：出口报检应提供（散装及国际规章包装豁免的除外项见原文）：**

1. 《出口危险化学品生产企业符合性声明》  
2. 《出境货物运输包装性能检验结果单》  
3. **危险特性分类鉴别报告**  
4. 危险公示标签、SDS 样本（外文须附中文译件）  
5. 需加抑制剂/稳定剂的，说明实际添加名称与数量  

检验还核对：组分/理化/危险类别是否符合国际规则及**输入国技术法规**；包装上是否有危险公示标签、是否随附 SDS。

**两条「危包证」不要混：**

| 单证（俗称） | 正式名称 | 谁去办 | 证明什么 |
|---|---|---|---|
| 性能单 | 《出入境货物运输包装性能检验结果单》 | **包装生产企业**（采购向供应商要；抬头须对出运工厂） | 这只「笼子」经试验合格 |
| 使用鉴定 / 危包证 | 《出境危险货物运输包装使用鉴定结果单》 | **出口危险货物生产企业**（我司/出口部向属地海关） | 这票货这样用这个笼子合格 |

申请入口：中国国际贸易单一窗口 → 货物申报 → 其他报检 → 出境包装报检（报检类别：危包使用），施检机关为**企业所在地海关**。

性能单与使用鉴定的**有效期以证书栏目 + SN/T 0370-2021 为准**。物流作业常用对照（仍以证书打印有效期为准）：

| 证书 | 常用有效期口径（SN/T 0370-2021 常见表述） |
|---|---|
| 性能单 | 自包装生产之日起一般不超过 **12 个月**；逾期再检等情形见标准（常改为自检验完毕起不超过 6 个月） |
| 使用鉴定 | 自**灌装之日**起算：第 8 类及带腐蚀副危多为 **6 个月**；其他危货包装多为 **12 个月**；**空运**使用鉴定常见 **3 个月**；且不得超过对应性能单有效期 |

海运性能单**默认不能**当空运证用。采购必须按模式分证，见 `export-packaging-procurement-raci.md`。

限量（LQ）/例外数量等若属「国际规章豁免使用危险货物包装」，129 号对性能单有除外表述——**必须书面确认本票包装导则确实豁免**，不得口头跳过使用鉴定。

### 3.3 公路（厂到港 / 厂到机场）

| 文件 | 物流要点 |
|---|---|
| 《道路危险货物运输管理规定》（交通部规章；2023 年第 13 号修改，**2026 年第 6 号仍保留相关条**） | **托运人**（第 28 条）：按国家规定包装、设标志，向承运人说明品名/危害/应急；危化品另交 SDS。**承运人**（第 34 条）：采取必要措施防脱落、扬散、丢失、燃烧、爆炸、泄漏——**未指定必须使用防泄漏托盘** |
| 《危险货物道路运输安全管理办法》 | 托运清单；装货人交付时包装无损坏、无泄漏；车辆按 GB 13392 悬挂标志 |
| JT/T 617《危险货物道路运输规则》 | 中国公路危货技术规则（对标 ADR 思路）；分类、包装使用、装卸、运输条件 |
| GB 13392 | 车辆标志 |
| GB 12268 / GB 6944 | 品名表与分类（与 UN 体系衔接） |

出口货在中国段仍是公路危货：必须危货资质承运商，不得当普通零担。缠绕膜对应「脱落」，不能替代一次包装防漏。

### 3.4 海运 / 海事 / 港口

| 文件 | 物流要点 |
|---|---|
| 《国际海运危险货物规则》（**IMDG Code 42-24**） | 中国海事局公告自 **2026-01-01** 强制实施。分类、包装导则、标记标志标牌、单证、积载隔离一律按此版 |
| 《船舶载运危险货物安全监督管理规定》（交通运输部令 **2024 年第 14 号**） | 进出港申报/许可；集装箱须提交《集装箱装箱证明书》；检查员现场检查后签署 |
| GB 40163-2021《海运危险货物集装箱装箱安全技术要求》 | 装箱作业与检查的强制国标 |
| 海事局《船载危险货物申报员和集装箱装箱现场检查员管理办法》 | 货报/船报人员、装箱检查员持证 |
| 上海港实务（洋山/外港） | EDI 电子装箱证明书；「装箱远程智慧管理系统」上传装箱照片；装箱点须经海事核查。**照片晚于 EDI 发送、信息不符不得装船** |

托运人侧海运核心单证（名称以承运人/海事系统为准）：

- 危险货物安全适运声明 / 包装危险货物申报  
- SDS（英文，海运常用）  
- 包装危险货物技术说明书（按当地海事/船代要求）  
- 使用鉴定结果单（正本/扫描按订舱要求）  
- 《集装箱装箱证明书》  
- 分类鉴定、UN 标记与箱标（UN 编号、正式运输名称、主/副危、海洋污染物、堆垛重量等）

港区仓必须有**港口危货作业资质**，许可证地址与进仓地址一致。嘉兴货走洋山还是外港、是否先报关后进港：**按当票船公司与码头，待补进 `04-operations`**。

### 3.5 空运 / 国际快递

| 文件 | 物流要点 |
|---|---|
| 《民用航空危险品运输管理规定》（交通运输部公布，2024 年修订文本） | 托运人：分类/包装/标记/标签；签署危险品运输文件的人员须培训合格；文件真实完整；国际运输文件加英文；相关文件保存 **不少于 24 个月**；禁止普货夹带或匿报 |
| ICAO《危险品安全航空运输技术细则》 | 空运的国际法律技术底本 |
| IATA 《危险品规则》（DGR）**当年有效版** | 航司/货代操作本；包装说明（PI）、限量、客机/货机差异以当年 DGR 为准 |
| 航司收运手册 | 可能比 IATA 更严（禁运清单、电池、香水、涂料内包装） |

样品快递：发票可写 sample，仍须 **customs value**；危货样品不得当普货快递。空运包装与海运包装、性能单必须按模式分开核对。

### 3.6 许可与管制（物流只做拦截，不自行审批）

下列**不是**「危包证替代品」。品名/组分一旦疑似，停订舱，升级 EHS / 进出口 / 法务。

| 管制 | 主管 | 涂料场景举例 |
|---|---|---|
| 易制毒化学品进出口许可 | 商务部等 | 丙酮、甲苯、丁酮、醋酸酐等溶剂 |
| 易制爆危险化学品 | 公安 | 部分高危原料，成品漆少见 |
| 监控化学品 | 工业和信息化 / 商务 | 成品涂料通常不涉及 |
| 两用物项和技术出口许可 | 商务部；《两用物项和技术进出口许可证管理目录》 | 不看 HS 是否列明，看物项本身是否受控 |

### 3.7 输入国（129 号公告强制企业保证）

出口产品须符合**输入国家或地区技术法规、标准**。中国海关检验会查标签/SDS 是否与输入国要求相符，但**不替代**目的国清关。

出口欧洲（战略重点）物流至少要能问到：

| 主题 | 谁主责 | 物流卡点 |
|---|---|---|
| CLP 标签 / REACH 注册或唯一代表 | EHS / 法规 | 外箱 GHS 与运输菱形标不要贴错层 |
| ADR（欧洲公路） | 欧洲收货物流 | 海运到港后欧洲段分类/包装是否仍适用 |
| 德国进口商、VAT | 销售/财务 | 贸易条款与进口商身份 |

输入国细则未写入本仓库前，出运欧洲票单独开检查表，不套用国内公路标签习惯。

## 4. 物流部出运闸门（缺一项不订舱 / 不送港）

内部流程节点见 `export-process-revised.md`（S1/S2/S3、首出口检测、罐装 UN）。本表只列**法规闸门**。

| # | 闸门 | 合格标准 |
|---|---|---|
| G1 | 运输身份 | 分类鉴定与 SDS14 一致；已判定是否目录危化品、是否运输危货、主危/副危/包装类 |
| G2 | 包装资产 | 性能单抬头 = 出运工厂；UN 码/年份/包装类与实物一致；海/空模式匹配；在有效期内（采购适用性声明） |
| G3 | 使用鉴定 | 使用鉴定结果单覆盖本票件数与灌装日；8 类/空运有效期未过 |
| G4 | 产地检验 | 符合性声明、鉴定、SDS/标签样本已报属地海关；取得检验电子底账或约定放行指令 |
| G5 | 首出口 | 该国首次出口的检测/测试 Lead-time 已进入计划 Milestone（与现流程「1st time export test」同一动作） |
| G6 | 公路 | 危货承运商；托运清单/SDS；装车无破损渗漏；车辆标志 |
| G7 | 海运则 | IMDG 42-24 正式运输名称与标签；船东/船代订舱资料齐；持证检查员监装；装箱证明书与远程照片时序正确 |
| G8 | 空运则 | 当年 IATA 可运；DGD 签署人有培训资质；客机/货机与 PI 正确 |
| G9 | 管制品 | 组分不在易制毒/两用未证清单；或许可证已签发 |
| G10 | 单证一致 | 发票、箱单、报关、危包证、舱单、鉴定上的品名、UN、件数、重量一致 |

**禁止：** 无使用鉴定出运危货；海运证套空运；鉴定与 SDS14 打架仍装车；普货渠道夹带涂料/固化剂；未监装先出装箱证明书。

## 5. 部门分工（与现有 RACI 对齐）

| 事项 | 主责 | 物流/出口做 | 不做 |
|---|---|---|---|
| 分类鉴定、SDS、GHS 公示标签 | EHS / Order Clearing | 收受控版本，发现冲突停运 | 现场改分类 |
| 性能单采购、抬头、海空分证、S2/S3 | **采购** | 提出本票模式与工厂抬头；形式复核 | 替采购问供应商「海运证能否空运」 |
| 使用鉴定、产地检验、报关、订舱、海事资料 | **出口 / 物流** | 办证与出运 | 维护包装主数据 |
| 罐装按 UN、生产日精确到日 | 生产 & QC / 计划 | 核对出库包装与证 | 现场换桶凑证 |
| 公路承运商资质 | 物流 | 选用危货资质 | 普通零担凑时效 |
| 港区装箱监装 | 港区仓 / 持证检查员（3PL） | 约定有资质场站 | 自管仓无证签装箱证明 |
| 易制毒 / 两用许可 | EHS + 进出口 + 法务 | 拦截并升级 | 口头判断「应该没事」 |

细节：`export-packaging-procurement-raci.md`。

## 6. 必须升级 EHS / 法务 / 属地海关的情形

- 鉴定报告与 SDS 第 14 章冲突  
- 新品无运输分类或未完成目录判定就要出运  
- 海运 / 空运 / 快递 / 国内公路标签或包装导则不一致  
- 疑似易制毒、易制爆、监控化学品、两用物项  
- 客户或货代要求「按普货报」或「不要危包证」  
- 输入国（尤其欧盟）标签、REACH、禁止用途不清  
- 批次检验、属地海关窗口或港口作业新通知与本文件不一致  

升级后：书面结论回写本文件或 `export-packaging-un.md`，不要只留在聊天里。
