# GHS 分类 ↔ TDG 运输分类对照（危货物流用）

## 1. 结论（给仓配 / 进出口）

| 判断 | 说明 |
|---|---|
| **对照表整体可用** | 作为培训与快速排查的**教学对照**，方向与业界常用 GHS–TDG 对应关系一致 |
| **不能替代正式分类** | 贴运输标、选包装、报关申报以 **分类鉴定报告 + SDS 第 14 章（运输信息）** 为准 |
| **GHS ≠ TDG** | SDS 第 2 章 GHS 象形图（尤其「腐蚀」）**不等于**必须贴 TDG 第 8 类运输标 |

与 Vicky（进出口）口径一致：**仅当鉴定报告或 SDS 运输信息注明主危/副危时，才加贴对应运输标签**；不得因 GHS 有腐蚀图就加贴 8 类副标。

---

## 2. 核对意见（相对附件表）

### 2.1 判定为正确（可入库）

- 爆炸品、易燃液体 Cat.1–3→第 3 类、易燃固体→4.1、自反应/自燃/遇水放出易燃气体→4.1/4.2/4.3、氧化性液体/固体→5.1、有机过氧化物→5.2  
- 金属腐蚀 Cat.1→第 8 类；皮肤腐蚀 1A/1B/1C→第 8 类  
- 急性毒性 Cat.1–3→6.1；Cat.4/5→非危险货物（就该危害而言）  
- 易燃液体 Cat.4→非危险货物（运输闪点门槛通常 ≤60℃）  
- 多数健康危害（眼损伤/刺激、致敏、致突变、致癌、生殖毒性、STOT、吸入危害）→**非 TDG 危险货物**  
- 水环境危害 Acute 1 / Chronic 1–2→第 9 类（海洋污染物语境）；其余多为非危险货物  
- 表底注「GHS 多数健康危害不在 TDG 范围内」— **正确且应作为培训重点**

### 2.2 使用时需加注的细点（不否定整表）

| 点 | 说明 |
|---|---|
| 氧化性气体→表写「5.1」 | 正式运输常见为 **主危 2.2 + 副危 5.1**，不宜理解成纯 5.1 包装类 |
| 易燃气体 Cat.2→「非危险货物」 | 常见教学对照口径；边缘气体仍可能按正式气体判定归入 2.1，**个案看鉴定/SDS14** |
| 压力下气体→2.2 | 若同时易燃/毒性，主危可能是 2.1/2.3，不是一律 2.2 |
| 水环境→第 9 类 | 多对应 UN3077/3082 及海运海洋污染物标记；公路/空运细则因模式而异 |
| GHS「腐蚀」象形图 | 可用于 **皮肤腐蚀 / 严重眼损伤 / 金属腐蚀**；其中 **严重眼损伤≠TDG 第 8 类**（见下节） |

### 2.3 仓配最易错点（必训）

1. 只看 SDS **第 2 章** GHS → 错贴运输标  
2. 看见腐蚀象形图 → 自动贴 8 类（可能只是 **眼损伤**，运输非 8 类）  
3. 鉴定报告与 SDS14 冲突时自行选一个 → 应升级 EHS/进出口，以受控版本更新对照表

## 3. 对照总表（附件誊清 + 物流备注）

> 「非危险货物」= **就该 GHS 条目而言**不构成 TDG 危险货物分类依据；同一产品可因**其他** GHS/试验结果仍为危险货物。

## 4. 仓库贴标作业规则（可执行）

1. **主数据**：料号 → 分类鉴定 + SDS 第 14 章 → 主标 / 副标清单（附图）  
2. **禁止**：仓管员根据 SDS 第 2 章 GHS 图自行加贴运输标  
3. **副标**：仅当运输信息写明副危（如 6.1、8）时加贴  
4. **冲突**：鉴定 ≠ SDS14 → 停发/停贴，升级进出口 + EHS，更新对照表后再作业  
5. **模式**：公路 / 海运 / 空运 / 国际快递标签与豁免不同，出口票单独核对

## 5. Agent / Skill 使用方式

遇到「GHS 有××为什么不贴运输标」「副危要不要贴」「火焰标/腐蚀标/鱼树标」类问题：

1. 读本文件 + `.cursor/skills/dg-ghs-tdg-labeling/SKILL.md`  
2. 先分清用户说的是 **GHS（SDS2）** 还是 **TDG（鉴定/SDS14）**  
3. 给出：是否应贴运输标、缺什么单证、是否升级 EHS  
4. **不签发**正式分类或法律意见；建议由持证人员确认
