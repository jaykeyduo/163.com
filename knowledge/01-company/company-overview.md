# 公司总览

## 公司身份

- 公司/品牌名称：美凯威奇涂料（Mankiewicz）
- 形态：集团公司；多国设有涂料工厂
- 总部：德国汉堡（Hamburg）
- 本 Agent 聚焦生产基地：中国嘉兴工厂
- 主营涂料品类（业务单元）：
  1. 汽车涂料（Automotive）
  2. 一般工业涂料（General Industrial）
     - 含小分支：风电、游艇、其他一般工业
  3. 航空涂料（Aerospace）

## 组织与职责

### 中国物流经理管辖范围

- 地理：中国
- 物流部下属机构：
  - **出口部门**（出口 Initiate Checklist 的 Owner）
  - **进出口部门**（报关、产地检验、危包使用鉴定等）
  - **仓储部门**
    - 工厂内仓（嘉兴独山）
    - 外仓：长春、沧州（2 个）
- 当前重点：拓展出口业务
- **出口抬头（已锁定）：** 未来出口一律 **独山** 抬头；不再用金山抬头出口

### 德国总部与嘉兴物流分工

| 环节 | 职责归属 | 说明 |
|---|---|---|
| 进口运输供应商（空运/海运） | 德国指定 | 成品/半成品以 **CIF** 交付至中国工厂 |
| 国内销售货源结构 | 中国侧组合 | 进口成品 +（进口原材料 & 国内采购原材料）本地生产 |
| 进口产品交期 | 计划（MP）协调德国 | |
| 国内生产交期 | 计划（MP）协调采购 / 生产 / 物流 | |

### 与其他部门接口（待补细）

- 计划（MP）：交期协调核心
- 采购 / 生产 / 销售 / EHS / 财务：接口细节待后续轮次补充

## 市场边界

- 主要销售区域：中国内销为主
- 内销 vs 出口：内销约 **99%**；出口业务在拓展中
- Agent 咨询默认覆盖范围：
  1. 嘉兴出口欧洲战略
  2. 中国国内配送
  3. 原材料进厂（含进口与国内采购相关物流）

## 备注 / 对框架的启示

- 货流不只是「嘉兴→欧洲」，核心现实是 **德国/海外 → 中国（CIF 进口）→ 中国客户**，外加出口拓展。
- 网络节点需显式包含：嘉兴内仓、长春外仓、沧州外仓。
- 交期责任在 MP，物流顾问建议需区分「进口交期」与「本地生产交期」两条链。
