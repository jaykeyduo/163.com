# 出口业务 Initiate 后 — 物流跨部门 Checklist（v1）

> **触发：** 业务 / PC 已提出出口意向（有产品、目的国或客户，S1 可尚未填完）。  
> **Owner：出口部门**（物流部下属）。**进出口部门、仓库**同属物流部：进出口答报关/产地检验相关；**仓库只答仓库段**。  
> **目的：** 排产锁定前一次问清；**红灯不进 Filling Order**。  
> **作业表：** `deliverables/出口Initiate跨部门Checklist.xlsx`（勾选 + 绿/黄/红）。  
> **不是：** 出运当天报关/订舱单（Phase IV + 法规地图 G1–G10）。  
> **本阶段目标：能合法出中国国门。** 目的国 REACH/CLP/ADR 暂不作为 initiate 红灯（法规地图仍保留输入国条文，出运欧洲时另案）。

**已锁定口径**

| 项 | 口径 |
|---|---|
| 出运抬头 | **一律独山**，不再询问金山 |
| 相容性 | **海关要求才做**；未要求则本项不适用 |
| 时限 | **暂不规定天数**；整厂出口流程图做出后写入 |
| 首出口缓冲天数 | **暂不规定**；流程图做出后写入。仍须判定「是否该国首出口」 |
| 会签 | **暂不强制**；意义待探讨（见文末） |

**出口部门先填再发问（最小数据包）：** 目的国、收货人类型、拟运输方式、样品还是批量、期望出运周。抬头固定独山，不必问工厂。缺上述项，先退回业务。

## 0. 结果判定

| 灯 | 含义 | 出口部门动作 |
|---|---|---|
| 绿 | 该项书面齐、无冲突 | 可进入下一阶段 |
| 黄 | 可并行（补证、补购）；天数待流程图 | 写入 Milestone，责任人 + 日期（日期能填则填） |
| 红 | 身份/包装/许可/中国出境条款未定或打架 | **停排产、停订舱** |
| 不适用 | 本票不涉及（如海关未要求相容性、本阶段不做目的国） | 勾选「不适用」，不算红灯 |

出口部门在票头勾选「本票可进入 Filling Order」即放行；**不要求**业务/采购/计划联合签字（会签待探讨）。

## 1. 按部门：出口部门要 Check 什么

只收书面（邮件 / S1 / S3 / 受控 PDF），不收「应该可以」。

### 1.1 业务 / PC（Sales）

| # | 要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| B1 | 目的国、最终收货人、是否终端客户还是汉堡总部/关联方 | 国别、全称、地址类型 | 缺国别=红 |
| B2 | 贸易条款（Incoterms）——中国出境报关所需 | 条款书面；谁付国际运费/保费与报关一致 | 完全未定=红 |
| B3 | 10 位产品码 + 是否配套固化剂/稀释剂（分票还是一套） | 码已定义；配套品各自运输身份不混报 | 无码=红 |
| B4 | 数量、包装意向、样品还是商业出货、货值币种 | 数量与币种可报关；样品仍有 customs value | 无货值=黄（报关前须绿） |
| B5 | 客户交期是否把出口当国内交期承诺 | 未用国内交期锁死出口票 | 已对客户锁死国内交期=红 |
| B6 | S1（Export Request Sheet）：产品 + 包装 | S1 已交；出口桶码 ≠ 内贸桶码 | 未填=红 |
| B7 | 客户有无额外包装/标签/托盘/文件要求 | 非标有主责，不默认仓配兜底 | 非标无主责=黄 |

B2 **不**卡目的国 VAT/进口商资质（先出国门）。

### 1.2 采购

| # | 要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| P1 | S2 该料号是否已有标准出口包装 | 有 S2；新包装评估默认不推荐 | 无 S2 且要新包装=红 |
| P2 | S3 性能单抬头是否为 **独山** | 与分类鉴定、危包证抬头一致；**禁止金山抬头出口** | 非独山=红 |
| P3 | 运输方式海 / 空 / 海+空；性能单是否覆盖 | 采购书面适用性声明；海运证默认不可套空运 | 模式未声明=红 |
| P4 | 铁桶 + 外箱齐套、UN 与证一致、在有效期内 | 缺纸箱证不得称齐套 | 缺证=红；有补购 ETA=黄 |
| P5 | 库存是否够本票；不够的补购 ETA | 数量 + ETA；到货带 UN+年份 | 无 ETA=红 |
| P6 | 是否 UN 年切换（大口隔离 / 小口报废） | 已通知仓/生产/计划/出口 | 年切换未通知=黄 |

出口对采购：要适用性声明，不替供应商判断海运证能否空运。

### 1.3 Order Clearing（SDS / 标签）

| # | 要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| L1 | SDS 第 14 章 + 中文件；外文须有中文译件（129 号出口报检） | 受控版本与料号一致 | 无 SDS=红 |
| L2 | 危险公示标签样本（中国出口报检用） | 与运输菱形标分层、不混贴 | 无样本=黄（报检前须绿） |
| L3 | 运输标签只按鉴定 + SDS14 | 不因 GHS05 自动加 8 类副标 | 与鉴定冲突=红 |

输入国 CLP 标签本阶段 **不适用**。

### 1.4 EHS

| # | 要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| E1 | 是否《危险化学品目录》内（涂料常见 2828） | 书面是/否；是则走 129 号产地检验 | 未判定=红 |
| E2 | 运输分类鉴定有效；UN / 类 / 包装类 / 副危 | 鉴定 ↔ SDS14 一致 | 无鉴定或打架=红 |
| E3 | 是否易制毒 / 易制爆 / 监控化学品 / 两用物项 | 否，或中国出口许可证已启动 | 疑似未升级=红 |
| E4 | 是否需抑制剂/稳定剂（报检说明） | 不需要，或名称数量可报检 | 应加未说明=红 |
| E5 | 目的国 REACH/CLP/ADR | **本阶段跳过（不适用）** | 不适用 |

### 1.5 实验室

| # | 要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| R1 | 粘度 / 密度 / 组成（包装选型） | 已提供或有承诺日期 | 选包装前缺失=黄 |
| R2 | 内容物–包装相容性 | **仅当海关要求时做**；未要求=不适用 | 海关已要求且无计划=红 |
| R3 | 出口 13 位码 | 与内贸码区分 | 未申请不阻塞 initiate，阻塞灌装=黄 |

### 1.6 计划 MP

| # | 要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| M1 | 是否该国 **首出口**（出口部门判定后通知 MP） | 是/否已标记。**缓冲天数待整厂流程图后填** | 未判定是否首出口=红；已标记待天数=黄 |
| M2 | Filling Order 用出口 tin / 桶码（≠ 内贸） | 系统码已分开 | 混码=红 |
| M3 | 排产 vs 包装到货 vs 灌装日 vs 使用鉴定有效期 | 灌装日落在证有效期内 | 对不上=黄 |
| M4 | 配套固化剂/稀释剂同期可供、分票规则 | 分票身份各自绿 | 主剂绿配套红=黄 |

### 1.7 生产 & QC

| # | 要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| Q1 | 罐装单带 UN、现场按单取桶 | 知悉出口桶 ≠ 内贸桶 | 未知=黄（排产前须绿） |
| Q2 | SAP 生产日期精确到日 | QC 确认可做到 | 只能到月=红 |
| Q3 | 小口年切换旧包装报废可执行 | 与采购通知一致 | 未对齐=黄 |

### 1.8 仓库（只答本段）

| # | 要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| W1 | 出口 UN 包装收货核对 UN+年份、与性能单一致 | 有核对标准，异常退采购 | 无核对习惯=黄 |
| W2 | 年切换：大口新盖隔离（纪要：新盖→3 号仓） | 仓知隔离位置 | 年切换票未知=黄 |
| W3 | 出口货与内贸货可分 | 不混放、不混贴 | 无区分=黄 |
| W4 | 出库贴标：运输标 vs GHS 谁贴 | 与 Order Clearing 一致 | 谁贴未定=黄 |

### 1.9 进出口部门（物流部下；与出口部门可同组则合并勾选）

| # | 要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| I1 | 本票是否走危化品产地检验（129 号）路径已清楚 | 知属地报检、符合性声明、电子底账 | 危化品未定路径=红 |
| I2 | 使用鉴定（危包证）申请窗口与所需齐套资料已知 | 性能单+鉴定+SDS 能对上独山抬头 | 不知如何办证=黄 |
| I3 | 拟运输方式对应海运海事 / 空运 DGD 差异已知 | 不把海运证当空运用 | 模式不清=红 |

### 1.10 财务（中国出境单证）

| # | 要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| F1 | 发票抬头、币种（报关用） | 与拟报关路径一致 | 未定=黄（报关前红） |
| F2 | 运费/保险谁付（相对 Incoterms） | 与 B2 一致 | 与业务不一致=红 |
| F3 | 目的国进口商 / EORI / 境外 VAT | **本阶段跳过（不适用）** | 不适用 |

## 2. 询问顺序（并行；不含固定天数）

```text
业务最小数据包齐 → 出口部门开 Checklist（Excel）
并行：采购包装 │ Order Clearing+EHS 身份 │ 实验室物性 │ 进出口办证路径
出口部门判定是否该国首出口 → 通知计划（天数待流程图）
计划 + 仓 + 生产：窗口与现场规则
红灯升级；黄灯记 Milestone
出口部门勾选「可进 Filling Order」→ 包装锁定通知
```

**硬停：** E2 鉴定打架、P2 非独山抬头、P3 海空证混用、E3 管制未证、B2 出境条款全空、B5 已用国内交期锁死出口、B3 无产品码。

## 5. 会签：待探讨（本版不强制）

先前「会签」的意思是：业务、采购、计划、出口在同一张纸上签字，表示「各部门都答完、可以排产」。**不是**海关或合同上的联合印章。

未强制的原因：你认为意义未清。可选替代：仅出口部门在 Excel 票头勾「可进 Filling Order」。若以后要会签，再定：谁签、签什么、不签能否排产。
