# 出口业务 Initiate 后 — 物流跨部门 Checklist（草稿，待 review）

> **触发：** 业务 / PC 已提出出口意向（有产品、目的国或客户，S1 可尚未填完）。  
> **目的：** 物流（进出口牵头）在排产锁定前，向各部门一次问清；**红灯不进 Filling Order**。  
> **不是：** 出运当天的报关/订舱作业单（那是 Phase IV + 法规地图 G1–G10）。  
> **本版状态：`draft`。** 请在文末「Review 决策点」批注后，再改 `active`。

**建议时限：** initiate 后 **3 个工作日**内完成一轮书面回复；包装缺货/首出口/新鉴定可并行拉长，但必须写入计划 Milestone。

**物流自己先填再发问（最小数据包）：** 目的国、收货人类型、拟运输方式、出运工厂（默认独山）、样品还是批量、期望出运周。缺这 6 项，先退回业务，不向全员群发。

## 1. 按部门：物流要 Check 什么

每条格式：**问对方什么 → 合格长什么样 → 灯**。物流只收书面（邮件 / S1 / S3 / 受控 PDF），不收「应该可以」。

### 1.1 业务 / PC（Sales）

| # | 物流要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| B1 | 目的国、最终收货人、是否终端客户还是汉堡总部/关联方 | 国别 ISO、全称、地址类型（工厂/仓/住宅） | 缺国别=红 |
| B2 | 贸易条款（Incoterms）+ 谁当进口商、谁付关税 VAT | 条款与进口商书面一致；DDP 须有人认税 | 未定=红 |
| B3 | 10 位产品码 + 是否配套固化剂/稀释剂（分票还是一套） | 码已定义；配套品各自运输身份不混报 | 无码=红 |
| B4 | 数量、包装意向、样品还是商业出货、货值币种 | 数量与币种可报关；样品仍有 customs value | 无货值=黄（报关前必须绿） |
| B5 | 客户要的交期 / OTIF 承诺是否已含出口缓冲 | 未向客户承诺「国内交期」当出口交期 | 已对客户锁死且不含首出口=红 |
| B6 | S1（Export Request Sheet）是否已填：产品 + 包装 | S1 已交；出口桶码 ≠ 内贸桶码 | 未填=红（可与采购并行补字段） |
| B7 | 客户有无额外包装/标签/托盘/文件要求 | 非标需求有主责部门，不默认仓配兜底 | 非标无主责=黄 |

### 1.2 采购

| # | 物流要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| P1 | S2 该料号是否已有标准出口包装（一料号一条） | 有 S2 选项；新包装评估默认 **不推荐** | 无 S2 且要新包装=红（先评估） |
| P2 | S3：性能单抬头是否 = 出运工厂（独山/金山不可混用） | 与分类鉴定、拟办危包证抬头一致 | 抬头错=红 |
| P3 | 本票运输方式：海 / 空 / 海+空；性能单是否覆盖 | 采购书面适用性声明；**海运证默认不可套空运** | 模式未声明=红 |
| P4 | 铁桶 + 外箱等是否 **齐套**、UN 与证一致、在有效期内 | 缺纸箱证不得称齐套；UN/年份与实物规则已定 | 缺证=红或黄（有补购日期则黄） |
| P5 | 库存够不够本票；不够的补购交期 | 数量 + ETA 书面；到货须带 UN+年份 | 无 ETA=红 |
| P6 | 是否撞上 UN **年切换**（大口隔离 / 小口报废） | 采购已通知仓/生产/计划/出口 | 年切换未通知=黄 |

物流对采购：**要适用性声明，不替供应商判断「这张海运证能不能空运」。**

### 1.3 Order Clearing（SDS / 标签）

| # | 物流要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| L1 | SDS：第 14 章运输信息 + 中文件；外文出口须有对应中文译件 | 版本受控、与本料号一致 | 无 SDS=红 |
| L2 | 危险公示标签（GHS）样本是否按 **输入国** 要求 | 与运输菱形标分层，不混贴 | 输入国标签未定=黄（欧洲票常红直到 EHS 认） |
| L3 | 运输标签：只按鉴定 + SDS14 的主危/副危 | 不因 GHS05 自动加 8 类副标 | 与鉴定冲突=红 |

### 1.4 EHS / 法规（可与实验室同一接口时拆开）

| # | 物流要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| E1 | 是否《危险化学品目录》内（涂料常见 2828） | 书面是/否；是则走 129 号检验 | 未判定=红 |
| E2 | 运输分类鉴定是否有效；UN / 类 / 包装类 / 副危 | 鉴定 ↔ SDS14 **一致** | 无鉴定或打架=红 |
| E3 | 是否易制毒 / 易制爆 / 监控化学品 / 两用物项 | 否，或许可证路径已启动 | 疑似未升级=红 |
| E4 | 是否需抑制剂/稳定剂及添加说明 | 不需要，或名称数量可写入报检 | 应加未说明=红 |
| E5 | 输入国（尤其欧盟）REACH / CLP / 用途限制谁保证 | 有部门认领，物流不猜 | 欧洲票无人认=红 |

### 1.5 实验室（内部；ByRoy「Customer Lab」）

| # | 物流要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| R1 | 粘度 / 密度 / 组成等包装选型数据 | 已提供或承诺日期 | 采购选包装前缺失=黄 |
| R2 | 本组合是否需 **内容物–包装相容性**（首次包装常用） | 不需要，或自检/第三方计划 + 周期 | 海关可能要而没有=红 |
| R3 | 出口 13 位码是否已申请 | 与内贸码区分 | 未申请不阻塞 initiate，阻塞灌装=黄 |

### 1.6 计划 MP

| # | 物流要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| M1 | 本票是否该国 **首出口**（物流判定后通知 MP） | 是：Milestone **预留**首出口检测 Lead-time；否：常规交期 | 首出口未预留却已承诺交期=红 |
| M2 | Filling Order 是否用 **出口 tin / 桶码**（≠ 内贸） | 系统码已分开 | 混码=红 |
| M3 | 排产窗口 vs 包装到货 vs 灌装日 vs 使用鉴定有效期 | 灌装日落在证有效期内（8 类/空运更短） | 窗口对不上=黄 |
| M4 | 配套固化剂/稀释剂是否同期可供、分票出运规则 | 分票身份各自绿 | 主剂可出配套红=黄 |

首出口 Lead-time **天数仍待 Jason 回填**；未回填前按「有额外海关检测、不可当国内交期」处理。

### 1.7 生产 & QC

| # | 物流要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| Q1 | 罐装单能否带 **UN 号**、现场按单取桶 | 生产知悉出口桶 ≠ 内贸桶 | 未知=黄（排产前须绿） |
| Q2 | SAP **生产日期精确到日**（报关/危包用） | QC 确认可做到 | 只能到月=红 |
| Q3 | 小口年切换时旧包装报废是否可执行 | 与采购通知一致 | 未对齐=黄 |

Initiate 阶段不必验货，但必须确认现场规则可执行。

### 1.8 仓库

| # | 物流要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| W1 | 出口 UN 包装收货：核对 UN+年份、与性能单一致 | 仓有核对标准，异常退采购 | 无核对习惯=黄 |
| W2 | 年切换：大口新盖隔离（纪要：新盖→3 号仓） | 仓知隔离位置 | 年切换票未知=黄 |
| W3 | 成品退仓后出口货与内贸货物理/系统可分 | 不混放、不混贴 | 无区分=黄 |
| W4 | 出库贴标协同：运输标 vs GHS 标分工 | 与 Order Clearing 口径一致 | 谁贴未定=黄 |

### 1.9 财务 / 德国侧（按票选用）

| # | 物流要问 / 要看 | 合格标准 | 灯 |
|---|---|---|---|
| F1 | 发票抬头、币种、是否关联交易作价 | 与报关、提单一致路径 | 未定=黄（报关前红） |
| F2 | 运费/保险谁付（相对 Incoterms） | 与 B2 一致 | 与业务说法不一致=红 |
| F3 | 收货为汉堡/欧洲时：德方进口商、EORI | 有进口商 | DDP 无进口商=红 |

## 2. 建议询问顺序（并行，不要串成一条长链）

```text
Day 0  业务最小数据包（B1–B6）齐 → 物流开 Checklist
Day 0–1 并行：
         采购 P1–P5（包装能否做）
         Order Clearing + EHS L/E（身份能不能出）
         实验室 R1–R2（物性/相容性）
Day 1–2 物流判定：该国是否首出口 → 通知 MP（M1）
Day 2–3 计划 + 仓 + 生产：交期窗口与现场规则
        红灯升级；黄灯写入 Milestone
        全绿/可接受黄 → 包装锁定通知 → 才允许 Filling Order
```

**硬停：** E2 鉴定打架、P2 抬头错误、P3 海空证混用、E3 管制未证、B2 条款无人认税、B5 交期已对客户锁死但首出口未预留。

## 3. 一页邮件模板（物流发给各部门）

**主题：** 出口 Initiate Checklist｜【目的国】【10 位码】【SO/需求号】｜请 3 个工作日内书面回复

请各部门只回本部门表内条款（B/P/L/E/R/M/Q/W/F），答案写「绿/黄/红 + 附件或日期」。黄灯必须带责任人与完成日。红灯请直接升级，不要口头放行。

附件：S1 草稿、拟运输方式、出运工厂、期望出运周。
