# 产品与物流特性

## 产品组合（物流视角）

| 品类（BU） | 形态 | 典型包装 | 温控/特殊要求 | 危化品？ | 备注 |
|---|---|---|---|---|---|
| 汽车涂料 | 成品：液体涂料 | 桶、罐；约 **1–30 kg** | UV / 水性漆：5–35°C | 成品基本为危险品；部分水性漆可为非危 | FIFO **严格** |
| 一般工业（含风电、游艇等） | 成品：液体涂料 | 同上 | UV / 水性漆：5–35°C | 同上 | FIFO 要求相对不严 |
| 航空涂料 | 成品：液体涂料 | 同上 | UV / 水性漆：5–35°C | 同上 | FIFO **严格** |
| 半成品 / 原材料（跨 BU） | 液体为主 | 约 **5–200 kg**；大包装比例高于成品 | 视物料而定 | 视物料而定 | |

### 危化品结构（成品视角）

- **基本成品都是危险品**
- 一部分 **水性漆** 可为非危品
- 主要油性漆及配套 **固化剂、稀释剂**，以及多数水性漆相关，仍以危险品为主

## 国内运输危化品占比与类别

- 货量：国内运输 **绝大部分为危化品**
- 主要危险类别：
  - **第 3 类** 易燃液体（最主要）
  - **固化剂大部分为第 8 类**
  - 实际常见类别汇总：**3 / 6 / 8 / 9 类**

## 运输约束摘要

- 公路：以危险品零担为主；夏/冬对温度敏感货启用危险品温控（见网络文件）
- 海运：进口路径已运行（CIF）；出口欧洲尚无稳定运行（见网络文件）
- 空运：进口常用法兰克福→PVG；出口待拓展
- 铁路：待补充
