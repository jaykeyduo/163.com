# 出口包装 / 性能单 — 采购部门责任清单（RACI）

## 1. 结论

出口 UN 包装与性能单由**采购向供应商申办并采购**。采购必须搞清楚所买包装及性能单的**适用规则与齐套性**，对内交付「可用、可匹配危包证」的包装资产；**不得**买完后把「这张性能单适不适用于某运输方式/某工厂抬头」的默认判断责任推给出口部。

出口部：**提出本票运输方式与出运工厂抬头需求**，用齐套资料办危包证/报关；对采购交付物做**形式复核**，不替代采购做供应商端技术适用性判断。

---

## 2. 采购必须承担的责任（逐条）

| # | 采购责任 | 邮件事实依据 | 不可推给出口部的原因 |
|---|---|---|---|
| **P1** | **按正确「包装使用人/工厂抬头」申办性能单并采购**（默认独山/浙江出口用独山抬头；与分类鉴定、危包证抬头一致） | 金山抬头性能单无法与独山分类鉴定拼危包证；供应商明确不可改使用人、不可延期 | 抬头是采购向供应商下单/申办时的规格，不是事后出口部能改的 |
| **P2** | **下单前向供应商书面确认：运输方式适用范围**（海运 IMDG / 空运 IATA 是否需**分证**；海运桶/证**默认不可**直接当空运证用） | Angel 问海运证能否空运；Francis 仅称「听说不同」并转请进出口确认 | 适用性是**采购规格**的一部分；出口部可告知「本票走空运」，但**证是否覆盖空运**须采购对供应商确认后写入 S3 |
| **P3** | **性能单与实物 UN 码一一对应**（包装类型、密度/等级、年份、制造商代码、证书序号）；新年份/新证必须新印 UN，不得假设旧桶可套新证 | Francis 已说明 UN 组成；旧金山桶需换 PI:007 新桶 | 采购掌控供应商打码与到货验收标准 |
| **P4** | **包装类型齐套采购**：铁桶/纸箱等出口所需包装均须有**有效、抬头正确、模式匹配**的性能单；缺纸箱证不得声称包装齐套 | 多次催促纸箱性能单；Vicky 明确缺纸箱证无法办危包证 | 纸箱与铁桶同属采购包材；进度与齐套是采购交付 |
| **P5** | **有效期与库存可用性管理**：证有效期、剩余包材是否可继续用于拟定出运工厂；不能用则主动报废/隔离方案与补购计划 | 金山证无法改使用人；剩余包装可能报废 | 采购资产与供应商合约范围 |
| **P6** | **维护 S2/S3 主数据（采购 Owner）**：每包装料号选项、性能单摘要（抬头、UN、模式海/空、有效期、证书编号、PDF 路径）、一料号原则一条 | Phase II；泰国案暴露无清晰 S3 导致反复邮件确认 | 出口部用表办证，**不维护**采购主数据 |
| **P7** | **到货交付标准**：到货桶/箱须带约定 UN+年份；数量、缺货补订由采购闭环（如 128 需 / 到 100） | Brian 缺 28 只桶催订 | 供应保障属采购 |
| **P8** | **变更与切换通知**：新证/新 UN/年切换时，邮件通知计划、生产、仓库、出口、PC，并更新公共盘与 S3 | 会议纪要；公共盘更新纸箱证 | 采购发起变更，出口只接收受控版本 |
| **P9** | **采购完成时的适用性声明（强制）**：每笔出口包装订单闭环时，采购书面确认：①抬头 ②海/空适用 ③UN 与证一致 ④有效期 ⑤PDF 已入公共盘/S3。未声明视为未交付 | 8/17 推诿场景 | 把「判断」前移到采购交付门禁，而非出口临开证时再问 |
| **P10** | **规则能力建设**：采购自行掌握危包性能单基本规则（抬头一致、模式分证、UN 与证绑定、自然年等）；可请出口做**培训答疑**，但**作业判断与供应商确认**仍由采购签字负责 | 「请进出口帮忙确认」作为默认动作不可接受 | 出口是专家支持，不是采购的质检外包 |

## 3. 出口部边界（避免扯皮）

| 出口部做 | 出口部不做 |
|---|---|
| 告知本票：**出运工厂、海运/空运/快递、危包证需求与时间节点** | 代替采购向供应商确认「海运证能否空运」 |
| 用采购交付的证+鉴定办危包证；发现抬头/UN/模式不一致时**退回采购整改** | 在采购未提供模式适用结论时，默认为采购背书 |
| 对分类鉴定、报关、订舱负责 | 维护 S2/S3、催供应商开证进度的 Owner |

**协作一句：** 出口提**需求**（工厂+模式）；采购交**合格资产+适用性声明**；出口做**办证与出运**。
