# 运营总览

> 第 5 轮问答已写入（嘉兴仓 ↔ 生产/实验室 + 出库/承运/进口收货）。

## 厂内物流主链（战略重点 B）

### 1. 原料供给生产

| 步骤 | 责任 | 说明 |
|---|---|---|
| 1 | 计划（MP） | 下生产单 |
| 2 | 生产 | 排优先级 |
| 3 | 生产 | 在系统 **叫料** |
| 4 | 仓库 | 根据系统执行原料供给 |

- **卡点：** 待后续补充

### 2. 成品退仓（生产 → 仓）

| 步骤 | 责任 | 说明 |
|---|---|---|
| 1 | 生产 | 完工后 SAP **确认罐装单** |
| 2 | 系统 | 生成 **转运需求** |
| 3 | 仓库 | 设时间节点，**定时**按需求单到生产交接区提货 |

**已知卡点：**

1. 生产交接 **成品数量错误**  
2. **产品标签贴错**（与系统交接数量不符）  
3. 成品退库 **无波次概念**，无法预见退库时间  
4. 紧急完工产品 **无准确交付时间**（通常要过 QC；QC 不通过需重新调料）

### 3. 实验室 ↔ 仓库

| 步骤 | 责任 | 说明 |
|---|---|---|
| 1 | 实验室（多经 **TAC** 统一接口） | 系统申请领料 |
| 2 | 仓库（系统） | 按申请单配料 |
| 3 | 仓库办公室 | 交出现场 **纸质配料单** |
| 4 | 仓库现场 | 实物交接到实验室 **TAC 交接区** |

### 4. 出库到客户（主流程）

| 步骤 | 责任 | 说明 |
|---|---|---|
| 1 | 销售 | 销售订单 |
| 2 | **Shipping 团队** | 制作系统 **DO** → 生成拣货单 |
| 3 | Shipping | **打印拣货单**，交到与仓库的交接区域 |
| 4 | 仓库现场 | 按拣货单先后执行拣货装车 |
| 5 | 单据/标签 | **出完 DO、拣货单后马上制作** |

**异常处理（缺货 / 改地址 / 加急）：**

- 发生频繁  
- 现状：**具体问题具体分析**，每人有自己的流程与解决方式  
- **不统一、不标准化** ← 与战略痛点「客户需求多样化 vs 人力」「部门各司其职、仓配不兜底」强相关

## 进口到独山 — 仓内收货要点

| 项 | 做法 |
|---|---|
| 清点主体 | **仓库** |
| 清点内容 | **托盘数量**核对 |
| 明细核对 | 托盘上有 **托盘清单**；以托盘清单 vs **进口资料**为准 |
| 实物开箱 | 若海关查验 **未破坏原包装**，则 **不清点实物** |
| 系统入账 | **仓库办公室** 入 SAP |
| 差异处理 | 非特别异常数量级：仓库直接 **调增/调减**，并反馈 **计划 + 客服** |

## 备注 / 对框架与项目的启示

1. **成品退仓**是流程优化最高杠杆之一：无波次 + QC 不确定 + 数量/标签错误 → 直接推高仓内加班与交接争议。  
2. **出库异常非标**应立项做：异常分类 + 决策树 + 责任归属（Shipping / 销售 / 仓 / 计划），避免「仓配发货端无限兜底」。  
3. TAC 实验室链路相对清晰（系统申请 → 配料 → 纸质单 → TAC 交接区），可作其他接口对标。  
4. 承运商仅南/北两家：韧性与议价需后续在 `04-operations` 补名称与份额。  
5. 进口收货偏「托盘+单据」模式：差异调账权限在仓，需与合规/计划保持透明（已反馈计划+客服）。
